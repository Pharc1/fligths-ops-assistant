# Evidence Citation

## Quand afficher une preuve

Afficher un panel de preuve dès que la réponse contient :

- une valeur chiffrée ;
- une limite réglementaire ou constructeur ;
- une étape de procédure ;
- une conclusion MEL Go/No-Go ;
- une corrélation avec l'historique de maintenance ;
- une source demandée par le technicien.

## Règles d'affichage

1. Utiliser `display_panel` avec le mode le plus précis.
2. Pour un document, fournir le passage complet court, le snippet à surligner et l'identifiant source.
3. Pour un historique, fournir les entrées chronologiques et marquer les anomalies.
4. Pour une valeur, fournir la valeur, l'unité, les limites et le statut.
5. Ne pas afficher dix preuves si trois suffisent à justifier la réponse.

## Règles de réponse

- Ne pas cacher l'incertitude.
- Ne pas paraphraser une limite critique sans source.
- Si la preuve est faible, répondre "je n'ai pas assez d'éléments" au lieu de conclure.
