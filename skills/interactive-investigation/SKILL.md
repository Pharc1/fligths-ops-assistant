# Interactive Investigation

## Quand utiliser ce skill

Quand le technicien arrive sur un dossier déjà traité et demande une vérification ciblée :

- "Tu as trouvé quoi ?"
- "Tu as vérifié si une panne antérieure a causé ça ?"
- "C'est écrit où ?"
- "Cette valeur vient de quel manuel ?"

## Méthode

1. Identifier ce que le technicien veut vérifier : document, historique, pièce, valeur ou procédure.
2. Lire le contexte incident déjà disponible avant de relancer une recherche.
3. Rechercher uniquement les sources nécessaires pour répondre à la vérification.
4. Comparer les résultats à l'incident courant.
5. Afficher un panel si la preuve visuelle aide le MRO à vérifier rapidement.
6. Répondre court : conclusion, niveau de confiance, prochaine vérification utile si nécessaire.

## Règles

- Ne pas refaire un rapport complet si la question est ciblée.
- Ne pas multiplier les panels : afficher seulement ce qui aide la décision immédiate.
- Si plusieurs sources se contredisent, le dire explicitement et recommander une escalade.
- Toujours distinguer ce qui vient du dossier incident, de l'historique et de la documentation certifiée.
