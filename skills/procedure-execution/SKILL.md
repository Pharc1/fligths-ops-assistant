# Procedure Execution

## Quand utiliser ce skill

Quand le technicien demande à exécuter ou vérifier une procédure :

- remplacement d'une pièce ;
- test fonctionnel ;
- dépressurisation ;
- inspection séquentielle ;
- reprise après une étape terminée.

## Méthode

1. Vérifier la source de maintenance avant de lancer la séquence.
2. Afficher la source si le technicien demande à lire la procédure avant action.
3. Démarrer une séquence avec étapes ordonnées.
4. Attendre une confirmation du technicien avant de passer à l'étape suivante.
5. Mettre en évidence les avertissements avant l'action dangereuse, jamais après.
6. Clôturer la séquence quand toutes les étapes sont confirmées ou si le MRO annule.

## Règles

- Le ton est "navigation de conformité", pas tutoriel.
- Une seule étape active à la fois.
- Ne jamais inventer une étape manquante.
- Si la source n'est pas trouvée, bloquer la procédure et demander vérification manuelle.
